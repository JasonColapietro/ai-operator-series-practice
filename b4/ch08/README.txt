PRACTICE FILES, FICTION. The AI Operator Series, Book 4, Chapter 8, Your Data, Exported and Backed Up.
Everything named in these files is invented: Harbor & Home Cleaning, Dana Ruiz, Sam Rivera, every customer, every amount and every date. No file here holds a real password, key, account number or email address.

In the story, the bank and invoice exports in Sam's library repo are Dana's real records. In the practice files they are made up, like every row in the series. Treat them as real while you practice: finding them, naming their owner and keeping them out of tests is the skill.

audit-key.txt            What a good audit finds in a Book 3 library repo, and the answers that count as right.

names-in-tests.txt       The customer names Sam's tests copied from a real week, and the trap each one tests.
names-in-tests-key.txt   One set of made-up names that keeps every trap, the rules that make a set right, and what counts as wrong.

Book 3's practice files hold the repo these exercises read: practice/b3/ch10/sam/ is Sam's repo at the start of Book 3 chapter 10, with tests/test_reconcile.py, and practice/b3/ch03/harbor-home/ holds one week of exports.

Nothing here turns on a plugin, hook or setting in any tool until you copy a file into place yourself.
