======================================================================
PART 4. THE FIRST BRIEF FOR AN AGENT
======================================================================
Copy library/briefs/template.md to a new file in briefs/, named for the
job (reconcile.md on the practice route). Fill it from the block at the
top of everything-else.md, or from dana-first-agent-job.txt in the
b2/ch15 folder. Each block line feeds one part of the brief:

Block line        Goes to                 What to write
----------        -------                 -------------
Job               # Brief: (title)        the job, in a few words
Files             Input                   what it reads, and nothing else;
                                          which file wins if two disagree
(not in block)    Output                  the file the run must leave: its
                                          name, its parts, where it lands
From              Owner                   whoever keeps the step that
                                          "stays mine" accepts the result
(not in block)    Permissions             read the Files; create only the
                                          Output; never change, move or
                                          delete what it reads; never send,
                                          post, submit or pay
(not in block)    Limits                  how many passes and recounts;
                                          stop and say which check failed
(not in block)    Recovery                a missing or unreadable file:
                                          keep what's done, name the step,
                                          tell the Owner
Check             Acceptance, line 1      the Check line, word for word
                  Acceptance, line 2      one more check anyone could run
Rules             Failure cases           the case the rules must handle,
                                          beside an ordinary input and one
                                          with a field missing
Runs it now       (stays in the block)    the baseline Book 3 measures
                                          against

On the header line, write today's date after "Saved:", then
"Runs in: a coding agent (Book 3)" and "Setting: Manual". Leave
"Stop by:" and the Runs line at the bottom blank. The first run belongs
to Book 3.

A field you can't fill yet gets [CHECK: what is missing] in place of a
guess. That's a question for the Owner, or for Book 3.
