What the run does on each date (with the first step in place)
  - Run date Monday, February 8, 2027, or any day from Tuesday, February 2 to Sunday, February 7:
      week-schedule-feb-8-12.csv -> the full summary above.
      week-schedule-feb-1-5.csv  -> one line: the file covers February 1 to 5, 2027, and needs replacing. Then stop.
  - Run date Monday, February 1, 2027, or any day from Tuesday, January 26 to Sunday, January 31:
      week-schedule-feb-1-5.csv  -> a full summary (17 jobs, the Yarmouth line).
      week-schedule-feb-8-12.csv -> one line: the file covers February 8 to 12, 2027.
  - Any other run date, including every day from Tuesday, February 9, 2027 on:
      both files -> one line naming the dates they cover. That is the check working, not failing.
      A run on Tuesday, February 9 looks for the week of February 15, which neither file covers.

Without the first step (the opening scene's version)
  - Run on Monday, February 8, 2027, with week-schedule-feb-1-5.csv in the folder: the run summarizes it as if it
    were this week. 17 jobs, one Yarmouth line, nothing else to fix. The day lines carry the dates February 1 to 5.
