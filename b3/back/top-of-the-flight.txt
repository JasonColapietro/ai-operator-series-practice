PART 3. THE BOOK 1 TEST, AIMED AT THE REPOSITORY AND THE AGENTS
======================================================================
Tick a box only when you can show it today.

[ ] 1. Pushed to a private remote.
       Run git fetch, then git status. It says your branch is up to date with
       'origin/main', and the repo's page on GitHub says Private next to its name.
[ ] 2. No secret in the repo.
       git ls-files shows no .env, and  git log --all --oneline -- .env
       prints nothing, which means no commit ever held it.
       .mcp.json names a token's variable and never holds the token.
[ ] 3. The same skill runs in both tools.
       One row of the harbor-reply skill's tests/triggers.md, run in a fresh
       Claude Code session and a fresh Codex session, gives the expected result in both.
[ ] 4. The setup passes the Twenty-Year Test.
       Every line of chapter 16's checklist is passed or written as a next step
       with a date.

Then, in keepers.md under ## My settings, below Book 2's line, add or update:
Book 3 test: [NUMBER] of 4, run [DATE]
