PRACTICE FILES, FICTION. The AI Operator Series, Book 3, Before This Book (front of the book).
Everything named in these files is invented: Harbor & Home Cleaning, Dana Ruiz, Sam Rivera, every client, crew member, price, email address and phone number. The prices exist to be checked, not copied. The towns are real places in and around Portland, Maine.

For "Try this: Bring your folder"

starting-folder.txt        The pieces of library/ that Book 3 leans on, each with the Book 2 chapter that made it and the Book 3 chapter that uses it first. Tick it against your own folder.

starter-library/           A library/ folder as it stands at the end of Book 2, built from the Book 2 practice files, for readers who start with this book. Copy the whole folder somewhere you control and rename the copy "library". Every file in it is fiction. The .md files carry no practice-file header, because a skill's SKILL.md has to open with its frontmatter and the rest are meant to be used as they are. This README is their fiction label.
