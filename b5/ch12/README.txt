PRACTICE FILES, FICTION. The AI Operator Series, Book 5, Chapter 12, Deliver With Agents.
Everything named in these files is invented: Sam Rivera, Harbor & Home Cleaning, Dana Ruiz and every customer request. The towns are real places in and around Portland, Maine. Prices and rules come from ../../shared/harbor-home-business-facts.txt, which is their one home. No Suede AI price appears anywhere here.

For "Try this: Write your service standard"
  service-standard.md        Sam's seven protections. Figure 12.1 draws a short form of it. Use it as the blank.

For "Try this: One pilot deliverable, done with evidence"
  requests.txt               Four weekend requests: Dana's three test requests from the pilot scope, and one real one.
  faq.md                     Sam's FAQ page, the earlier deliverable the first price check was written for.
  delivery/                  The quote desk's four drafts for Dana to approve. The real deliverable.
  broken-saturday/           The same four drafts, with one planted flaw: a draft that books a Saturday. The practice input.
  broken-price/              The copy from Sam's step: a planted $300 price in a quote draft.
  checks/check_delivery.py   Listing 12.1. Python standard library only; nothing to install.
  evidence-template.md       One evidence-of-done record.
  sam-evidence-week1.md      Sam's record for the first live Saturday. Figure 12.3 draws it in short form.
  sam-incidents.md           The first entry in Harbor & Home's incident log.
  handoff-template.md        The handoff that closes a deliverable.
  answer-key.txt             What counts as right. Read it after you try.

For your playbook folder
  playbook-README.md         What Sam's playbooks/staffing-quote-desk/ holds and where each file came from.
  outward-rules.md           Listing 12.2, the rules-file section that keeps every outward action with a person.
  evals-cases.md             Sam's first eval set: twelve requests and what a right draft does with each.

Run the check from this folder:
  python3 checks/check_delivery.py ../../shared/harbor-home-business-facts.txt broken-saturday
On Windows, type py in place of python3.

Never write a password, a key, a door code or a real customer's records in any of these files.
Nothing here turns on a plugin, hook or setting in any tool until you copy a file into place yourself.
