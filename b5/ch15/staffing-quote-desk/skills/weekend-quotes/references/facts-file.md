# Where the facts come from

Each client keeps one approved facts file in their own drive, and the runbook names its exact location. The skill reads that file and nothing else. For the practice route it is ../../../../../../shared/harbor-home-business-facts.txt (the same file chapter 14 uses).

The file must state, in plain text:
- the service area, the towns served by request and any travel fee, and the places not served;
- each service with its "from" price and the size that price covers;
- the size above which a walk-through comes first;
- how booking and payment work;
- what the business does not do.

If the file is missing any of these, the skill marks [CHECK] and drafts nothing that depends on it.
