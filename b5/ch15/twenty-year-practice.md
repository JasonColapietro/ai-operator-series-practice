# Twenty-Year Test: the practice

Two questions for every part of the practice, asked in order:
1. Will this still work in twenty years? If no, don't build it.
2. Does it work only while I'm still here? If yes, redesign it until it works without me.

Six checks. Each line ends as a tick with a date, or as a next step with a date.

  (Markdown rules, Agent Skills folders, plain-text logs). Passed:

  test passes in Claude Code and in Codex). Passed:
- [ ] 3. Prices and terms are written down where I can point to them
  (pricing.md and the published terms page), never only in emails. Passed:
- [ ] 4. The client list lives in library/pipeline.md, not only in an inbox,
  a CRM or a social network's messages. Passed:
