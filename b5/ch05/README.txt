PRACTICE FILES, FICTION. The AI Operator Series, Book 5, Chapter 5, Machine-Readable or Invisible.
Everything named in these files is invented: Harbor & Home Cleaning, Dana Ruiz, Sam Rivera, every listing and every page. The towns are real places in and around Portland, Maine. The web addresses use example.com and other names reserved for examples, so nothing here reaches a real site. The prices exist to be checked, not quoted, and practice/shared/harbor-home-business-facts.txt is the one home for them: where any file here differs from it, the facts file wins.
Nothing in this folder connects to anything, and none of it turns on a plugin, hook or setting in any tool you open it with.

The practice site is a folder, not a hosted site. Open practice-site/index.html in your browser by double-clicking it, and open robots.txt and sitemap.xml in any text editor. To see what a crawler reads, right-click a page and choose View Page Source (in Safari, turn on the developer features first under Settings > Advanced, then choose Show Page Source). The site has planted problems. Find them before you read the key.
