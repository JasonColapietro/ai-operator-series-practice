# Before every send

Accounts: I send as Sam Rivera (personal email and personal LinkedIn, as listed in identity.md). Never as Rivera AI, never from a shared inbox.

1. The From line shows my own name, the one in identity.md. Anything else: stop and switch.
2. The To line matches this business's row in pipeline.md.
3. The row does not say "do not contact."
4. The attachment is this business's capture, with the date in the filename.
5. Under seventy words above the signature, ending on one question.
6. Every business named came from the engine's answer, with nothing added about it.
7. The footer has my postal address and the stop line.

Send once. Then find the message in Sent and write the date and time in the row.

If the send is unclear (an error, a spinner that never stops, nothing in Sent):
do not send again. Mark the row "unclear." Check Sent and the outbox in an hour.
Send again only when I can show the first one never left.

No agent sends. An agent may draft, check and fill in the row.
